1. **自己紹介タイム**：お題カード（全44種）に答えて「〇〇です。（お題）は△△です。」。答えは数秒だけ全員の画面に表示されて消えます（読み上げON可）。
2. **クイズタイム**：「〇〇さんの（お題）は何だったでしょう？」を4択で。早く正解した順に3点・2点、ほかの正解は1点。自分の問題は見守り。
3. 結果発表＋みんなの自己紹介の答え合わせ。

- 通信：PeerJS（WebRTC P2P）。ホストのブラウザが進行を管理。部屋コード／招待URL／QRで参加。
- 設定：お題の数 2/3/4（1人あたり）、表示時間 3/5/8秒、問題数 ぜんぶ/8/12/16。
- `config.js` で STUN/TURN・PeerJS サーバーを変更できます。
